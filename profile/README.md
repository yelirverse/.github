# Yelirverse

A small collection of personal web projects living at **[yelir.net](https://yelir.net)**.

## Sites

| Site | What it is |
|------|------------|
| [yelir.net](https://yelir.net) | The homepage: what I'm playing, watching and driving, plus a dog who will not give the ball back |
| [wowtoken.yelir.net](https://wowtoken.yelir.net) | World of Warcraft Token price tracker with history charts and Discord alerts |
| [ip.yelir.net](https://ip.yelir.net) | What's my IP, plus DNS, whois and certificate lookups |
| [health.yelir.net](https://health.yelir.net) | Live status of the sites and the server behind them |

## How it's built

- Python and FastAPI on a single small server, behind Cloudflare
- Every change goes through a pull request with automated tests
